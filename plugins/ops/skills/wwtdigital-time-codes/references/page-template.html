How this was built

Claude swept the private channels you belong to in the WWT Slack workspace and pulled every project number, Sales P&L, and indirect code it found in each channel's topic or purpose. Task numbers like 1001 are shown beside the code they belong to.

Reading the types

Project is a delivery project number (usually 8 digits, 100xxxxx). Sales P&L is the sales code for pursuit or new-biz time. Indirect covers internal buckets like GSE Indirect and Internship. When a channel lists both, bill delivery work to the project and pursuit work to the Sales P&L.

Coverage

Slack has no "list every channel I'm in" call, so channels are found from your recent messages plus name searches. A channel with no code in its topic or purpose doesn't appear here. Codes in Slack Connect channels from other workspaces are skipped.

Refreshing

Ask Claude to "refresh my time codes". It re-sweeps your channels and republishes this page at the same link.
