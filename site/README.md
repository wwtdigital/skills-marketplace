# Marketplace site

Static, no build step. Deployed to Vercel with **Root Directory = `site/`** and
Framework Preset = *Other*. `data/` and `downloads/` are generated by
`scripts/build_index.py` and committed by CI on every push to `main`, which triggers
the Vercel deploy.

Local preview:

```
python3 scripts/build_index.py
python3 -m http.server -d site 8080
```
